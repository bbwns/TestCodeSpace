## 0단계. 미리 알면 쉬운 것 (C/파이썬으로 비유)

| 웹 용어 | 비유 |
|--------|------|
| 서버 | 평생 실행되는 파이썬 프로그램. 요청 오면 처리 |
| 라우트 (app.get) | 파이썬 `if 경로 == "/": ...` 같은 분기 |
| SQLite DB | 엑셀 표 1개가 파일 1개 (`backup.db`) |
| 테이블 | 엑셀 표. 행(가로줄)=이미지 1개, 열(세로줄)=정보 항목 |
| SQL문 | 표에 "한 줄 추가"(INSERT), "읽기"(SELECT) |
| multer | 우체부. 파일을 uploads/에 내려놓고 파일명 알려줌 |
| JSON | 파이썬 딕셔너리 `{"제목": "강아지"}` 를 텍스트로 주고받는 것 |
| fetch() | 브라우저가 서버에 "데이터 주세요" 하는 것 |

> 📌 딱 하나만 기억: **요청이 오면, 서버가 처리하고, 응답을 보낸다.**

---

## 1단계. 전체 그림

**"이미지 올리면 서버가 저장해두고, 나중에 브라우저에서 다시 보여주는 것"**
ㅇㅇㅇㅇ
```
사용자 ──업로드──▶ 서버 ──저장──▶ [파일(uploads/) + 정보(backup.db)]
   ▲                                    │
   └──────── 갤러리로 보여줌 ◀──────────┘
```

---

## 2단계. 구성 요소 4덩어리

| 덩어리 | 역할 | 어디에? |
|--------|------|---------|
| 클라이언트 | 사용자 화면 (폼, 갤러리) | `public/index.html` |
| 서버 | 요청 받고, 저장하고, 응답 | `server.js` |
| 파일 저장소 | 이미지 "파일" 보관 | `uploads/` |
| DB | 이미지 "정보" 보관 | `backup.db` |

💡 핵심: **"이미지 파일"과 "이미지 정보"는 저장 장소가 다르다.** 파일은 폴더에, 정보는 표에.

---

## 3단계. 데이터 흐름

### ① 업로드
1. 이미지 + 제목 + 설명 넣고 [업로드] 클릭
2. multer(우체부)가 파일을 `uploads/`에 저장
3. 서버가 DB 표에 "한 줄 추가" (INSERT)
4. 성공하면 메인 화면으로 이동

### ② 목록 보기
1. 페이지 열리면 `fetch()`로 서버에 "목록 주세요"
2. 서버가 DB에서 "전부 읽기" (SELECT)
3. JSON으로 응답 → 브라우저가 갤러리로 그림

---

## 4단계. 핵심 코드 딱 5줄

```js
app.get('/', ...)              // "/"로 오면 페이지를 보내줌
app.post('/upload', ...)       // 업로드 요청 처리
db.run('INSERT INTO ...')      // DB 표에 한 줄 추가
db.all('SELECT ...')           // DB 표에서 읽기
fetch('/api/images')           // 브라우저가 서버에 목록 요청
```

> 자세한 건 `함수.md`를 참고!

---

## 5단계. 실행 방법

```bash
npm install   # 1번만
node server.js
```

브라우저에서 `http://localhost:3000` 접속!

> ⚠️ DB 스키마를 바꿨다면 `rm backup.db` 후 재시작.

---

## 6단계. 공부 실습 (순서대로)

1. `server.js`를 위에서 아래로 1번 읽기 (모르는 단어 표시만)

3. `server.js` 모든 줄에 "왜?"를 주석으로 적기
